# 台股彈幕 📈🚀

即時臺灣股市彈幕系統——一邊看大盤（發行量加權股價指數），一邊發匿名彈幕。純粹為了好玩。

## 功能

- **即時大盤**：伺服器每 5 秒輪詢證交所 MIS API，紅漲綠跌（台股慣例）
- **匿名彈幕**：完全匿名，訊息飛過去就沒了，不落地、不存資料庫
- **自動分房**：每房上限 100 人（可調），滿了自動開新房；彈幕只在房內廣播，控制伺服器頻寬成本
- **防洗版**：令牌桶限流（可連發 3 則，之後每 2 秒補一則額度），單則最長 50 字
- **模擬行情**：收盤時間或連不到證交所時自動切換隨機漫步假行情，開發不用等開盤

## 快速開始

```bash
npm install
npm start          # 正式模式：抓證交所即時行情
npm run dev        # 開發模式：SIMULATE=1，用模擬行情
```

打開 <http://localhost:3000> 就能玩。開兩個分頁可以看到彼此的彈幕。

## 環境變數

| 變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | `3000` | 伺服器埠號 |
| `ROOM_CAPACITY` | `100` | 每個房間的人數上限 |
| `SIMULATE` | 關 | 設 `1` 強制使用模擬行情 |

## 架構

```
server/
  index.js    Express + Socket.IO 主程式（分房、限流、廣播）
  market.js   證交所行情輪詢 + 模擬行情備援
  rooms.js    房間管理（滿房自動開新房、空房回收）
public/
  index.html  單頁前端
  style.css   深色主題、彈幕動畫
  app.js      Socket.IO 客戶端、彈幕軌道排程
```

### 成本控制設計

- 彈幕用 `socket.to(room)` 只對同房間廣播，一則訊息最多扇出 99 個連線
- 行情是全站共用的單一輪詢（不管幾個使用者，對證交所都只有一條輪詢），每 5 秒 `io.emit` 一次
- `maxHttpBufferSize` 壓到 4 KB，異常大封包直接擋掉
- 沒有資料庫、沒有訊息歷史，記憶體佔用只跟在線人數成正比

## 監控

`GET /stats` 回傳目前房間數、在線人數與行情來源：

```json
{ "rooms": 2, "users": 137, "capacity": 100, "marketSource": "twse" }
```

## 資料來源

大盤指數來自[臺灣證券交易所基本市況報導網站（MIS）](https://mis.twse.com.tw/)的公開 API，僅供個人趣味用途；請保持合理的輪詢頻率。
